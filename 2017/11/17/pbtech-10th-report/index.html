第10回ペパボテックカンファレンス～インフラエンジニアがもっとおもしろくできる！～を開催しました

イベント インフラ 登壇イベント
  • ツイート

ロリポップ！ を始めとした、ホスティング事業のインフラエンジニアをしている、 @takumakume です。 最近の自慢は周囲が糖質制限している中、暴飲暴食しても体重が一定であることです。

本日は 第10回ペパボテックカンファレンス を弊社の東京オフィスにて開催いたしましたのでレポートをしていきたいと思います！

ペパボテックカンファレンスは記念すべき第10回を迎えました！当日は、参加者38名で大盛況となりました。

今回は、「インフラエンジニアがもっとおもしろくできる！」というサブタイトルの通りインフラ特集としてお届けしました。 インフラ特集は 第5回 以来の開催です！

当日の状況は、こちらの togetter にまとめておりますので是非御覧ください！

それでは、当日の発表内容についてご紹介していきます。

発表内容のご紹介

(1) アクセス頻度予測を用いてサーバーリソースの増減を行う「計画的スケーリング」

技術部 インフラグループ @r_takaishi

こんにちは！@r_takaishiです。社内イベントで写真を撮ったりして日々過ごしています。今回は、ペパボ研究所と協力して開発した アクセス頻度予測を用いてサーバーリソースの増減を行う「計画的スケーリング」 について、課題やペパ研が提案した手法、実際にサービスに適用するにあたっての設計、評価などを紹介しました。今回はアクセス頻度予測の詳細は話さなかったので、そちらが気になる方はアクセス頻度予測に基づく仮想サーバの計画的オートスケーリングをぜひ読んでください。

(2) 物理サーバ構築のここんとこ ~MAASの話をしまーず~

ホスティング事業部 インフラチーム @ndsoea

皆様はじめまして@ndsoeaです。カンピロバクターは怖いもので、まだお酒やコーヒーと大好きな鶏肉をあまり食べることができません・・・ 今回の私のセッションでは、MAASの話をしまーず。MAASの話をしMAAS。。ということで、ベアメタル・プロビジョニングツールであるMAASのお話をさせて頂きました。 ロリポップ！マネージドクラウドの基盤構築にMAASを新しく採用させて頂いたので、その際に感じた他のベアメタル・プロビジョニングツールと比較してMAASのいいところや、MAASの基本的な動作、Podsと言われる仮想サーバを管理する機能について紹介させて頂きました。

(3) Webサーバ拡張における排他制御とパフォーマンスチューニング

ホスティング事業部 インフラチーム @takumakume

本セッションでは、ホスティングサービスである ロリポップ! で行われているWebサーバの機能拡張におけるレースコンディション問題を解決する排他制御についてお話しました。

ペパボでは ngx_mruby や mod_mruby というモジュールを使って、nginx や Apache HTTP Server の mrubyを用いた機能拡張を多数行っています。 セッションの中では、排他制御の必要性を簡単な実装例を元に説明しており、それにより生じるパフォーマンス劣化を最小限に抑えるためのポイントを計測結果と実績をもとにお話しています。

(4) 脆弱性管理サービス Veetaをリリースした

ホスティング事業部 @pyama86

こんにちは。顔だけが取り柄の @pyama です。今回の僕の発表では、僕がペパボにVulsを導入した際に、ペパボは複数サービスかつ1,000台超のサーバを抱えることから、統合管理が難かったこと、 そして、それを実現するためにVeetaを開発したという話をしました。

VeetaのクライアントであるVazはLight Vulsと言う位置付けで、Vulsのコードをベースに、パッケージの抽出に専念し、スキャンはVeetaで行うというアーキテクチャにしています。Veetaで今後やっていきたいことなどを話しましたが、冬から年始にかけて多くの場所でお伝えする機会があると思いますので、その際はぜひ会場におこしいただければ幸いです。

まとめ

今回はインフラ特集としてお届けしました。 発表内容としては、以下のようにインフラエンジニアの技術的な幅の広さを伺える内容となりました。

  • プライベートクラウドの運用技術
  • ベアメタルの構築技術
  • ミドルウェアの開発要素技術
  • 脆弱性管理技術

質疑応答タイムや懇親会にて活発にご質問やご意見をいただくことができて、ペパボでの取り組みをご来場いただいた方々にしっかりお届け出来たのではないかと思います。同時にエンジニアとしても多くのフィードバックを得ることができ、成長させていただいたことに感謝しております。

当日のペパボテックカンファレンスでは、「ペパカレ部屋」を設けてペパボカレッジに関する相談会も行い、こちらも大盛況となりました。 ペパボカレッジとは、既卒向けの新しいエンジニア採用枠で未経験でも、入社後1ヶ月にわたって行われる研修プログラムによって即戦力として働くことができるものです。詳しくは以下をご参照ください！

  • ペパボカレッジ6期生（東京勤務）
  • ペパボカレッジ6期生（福岡勤務）

ペパボテックカンファレンスは今後も開催していきますので、是非ご参加いただければと思います！
